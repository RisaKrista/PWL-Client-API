Student Part-Time Job Platform

Jalur presentasi (user flow a–g)

  1. a Registrasi & verifikasi Mahasiswa Isi data contoh → kode OTP (console server) → unggah file contoh → status Pending
  2. b Registrasi & verifikasi Employer Isi data contoh → kode OTP (console server) → dokumen → Dashboard Pending
  3. c Cari → filter → detail → lamar Matikan filter availability, buka Barista Akhir Pekan, lalu Lamar
  4. d Buat lowongan (UC1, AF1, AF2) Klik Publikasikan kosong (AF1); set status Pending di panel Demo (AF2)
  5. e Admin: verifikasi & moderasi Tinjau Fajar Hidayat; lalu Moderasi Lowongan
  6. f Employer kelola pelamar Klik pelamar → Terima → nomor telepon tampil
  7. g Akses Mahasiswa berakhir Jalankan pemeriksaan → Mahasiswa yang lewat masa berlaku menjadi Kedaluwarsa
Akun Admin: username admin / admin123 Data awal hanya berisi perguruan tinggi, periode, dan akun Admin; Mahasiswa dan Employer mendaftar sendiri. Kode OTP registrasi tampil di console server (dan di halaman pada mode pengembangan). Tombol "Isi data contoh" mengisi formulir agar demo lebih cepat.
